# MedSafe AI

## Prescription Safety Screening & Daily Timeline

MedSafe AI is a hackathon prototype designed to organize information from prescription-label images and provide a simple safety-review workflow.

## Problem

When users have multiple prescription labels, it can be difficult to organize the information and identify what needs professional review.

## Solution

MedSafe AI provides a simple workflow:

Scan / Upload
→ Process
→ Extract Information
→ Safety Review
→ Daily Timeline

## Features

- Prescription image upload
- Camera-based scan interface
- Multiple image selection
- Information extraction workflow
- Safety verification screen
- Daily timeline
- Responsive web interface

## Technology Used

- HTML
- CSS
- JavaScript
- VS Code
- Live Server

## Current Prototype

The current hackathon demonstration uses synthetic data for reliable testing.

The prototype does not provide medical advice or make automatic medical decisions.

## Future Scope

- Reliable OCR integration
- Real camera processing
- Trusted medication information database
- Multilingual label support
- Secure backend
- More robust safety-review engine

## Disclaimer

MedSafe AI is a prototype for demonstration purposes and is not a substitute for professional medical advice.
